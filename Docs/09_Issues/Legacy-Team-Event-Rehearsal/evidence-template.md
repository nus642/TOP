> 代码审查发现（只读追踪结论，分支内已修复）：
> - P1-1：裁判端提取任务仅在提取时预填场地，接受/开赛环节无场地校验，空场地会默认回退 '1' → 已改为强制继承 task.court，无场地阻断开赛。
