## 一、背景

Legacy 团体赛真实操作中发现：

1. 名单导入后，“队伍编号”随运动员序号递增，同队人员显示不同编号；
2. Master 页面缺少进入运动员名单库的直接入口；
3. 页面跳转不得通过 URL 传递裁判长密码或其他凭据。

本次采用最小修复，不修改 `data.php`、数据库结构、比赛状态机及核心执裁流程。

## 二、修复内容

### 1. 冻结队伍编号

- 同一队伍共享同一个 `team_code`，如 `T01`；
- 不同队伍依次使用 `T02`、`T03` 等短码；
- 每名运动员保留唯一 `id_code`，如 `T01-01`、`T01-02`；
- 重复导入不重复、不改号；
- 追加导入延续原有队内序号。

### 2. 名单页显示

`players.html` 的“队伍编号”列优先显示 `team_code`；旧数据缺少该字段时，保留安全回退显示。

### 3. Master 名单入口

Master 团体赛工具区增加“运动员名单”入口，只携带经过编码的赛事代码：

```text
players.html?code=<event-code>
```

URL 明确禁止包含 `pwd`、`password`、`referee_password`、token 或其他凭据。
