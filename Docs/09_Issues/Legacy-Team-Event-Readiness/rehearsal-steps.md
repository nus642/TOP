# 比赛日前完整预演步骤

> 用示例数据走通 Phase 0 → Phase 6 全链路。建议在正式比赛前 2 天完成。
> 示例数据位于 `Tools/legacy-team-event-readiness/team-event-sample-data.csv`

---

## 预演环境准备

- [ ] 确认 Legacy 服务可访问（Docker 或本地 PHP + MySQL）
- [ ] 确认数据库为空库或已清空上次赛事数据
- [ ] 准备示例 CSV 文件（`Tools/legacy-team-event-readiness/team-event-sample-data.csv`）
- [ ] 准备日程表 Excel（手动制作 2 场 VS 对阵）

---

## Phase 0: 赛事初始化

**操作人：裁判长**

1. 打开 `master.html`
2. 使用超管密码创建新赛事
   - 赛事名称：`预演团体赛`
   - 赛事类型：`team`（团体）
   - 场地数：`2`
   - 裁判长密码：记录为 `____`
3. 记录赛事码：`________`
4. 确认赛事创建成功（面板显示赛事信息）

**验证点：**
- [ ] 赛事码可登录 master
- [ ] 赛事类型为 team

---

## Phase 1: 导入大名单

**操作人：裁判长**

1. 在 master 面板找到"1.导入大名单"按钮
2. 上传 `team-event-sample-data.csv`（或 Excel）
3. 确认提示"大名单导入成功，提取了 24 人"
4. 在名单管理区域查看导入结果

**验证点：**
- [ ] 导入人数 = 24
- [ ] 4 个队伍各有 6 人
- [ ] 所有选手 checked_in = false（未签到状态）
- [ ] 队名正确（猛虎队/雄鹰队/蛟龙队/飞凤队）

---

## Phase 2: 日程建房

**操作人：裁判长**

### 路径 A（team_import.html）

1. 打开 `team_import.html`
2. 输入赛事码
3. 上传日程表 Excel
4. 确认解析预览：应有 2 个房间（T01, T02）
5. 点击"确认无误，一键建立所有排阵房间"

### 路径 B（master.html → handleImportTeamFile）

1. 在 master 面板找到"2.日程建房"按钮
2. 上传日程表 Excel
3. 确认预览表格：组别、左队、VS、右队
4. 可编辑队名和编号
5. 点击确认

**验证点：**
- [ ] 房间数 = 预期（2 个）
- [ ] 队名与大名单完全一致
- [ ] team_event 有对应房间数据

---

## Phase 3: 领队排阵

**操作人：领队 A（猛虎队）、领队 B（雄鹰队）**

每个领队独立操作：

1. 打开 `team_lineup.html`
2. 输入赛事码 + 房间号（如 T01）
3. 点击"查询对阵信息"
4. 选择己方队伍
5. 输入调度密码
6. 在排阵区编排每盘出场球员
   - 第 1 盘：张三 vs （对方待定）
   - 第 2 盘：李四 + 王五（双打）
   - 第 3 盘：赵六
7. 点击"锁定并提交全盘阵容"
8. 签名确认（手写签名）

**验证点：**
- [ ] 双方都提交后，master 面板显示"双方排阵完成"
- [ ] team_lineups 有对应记录
- [ ] 排阵中的选手姓名与 players 表完全一致

---

## Phase 4: 签到

**操作人：裁判长**

### 方式 1：逐个手动签到（预演推荐）

1. 打开 `players.html`
2. 登录（赛事码 + 裁判长密码）
3. 逐个切换选手签到状态
4. 确认所有选手 checked_in 变为 true

### 方式 2：模拟扫码签到（正式比赛推荐）

1. 球员打开签到页面（checkin.html）
2. 输入赛事码
3. 找到姓名 → 签免责书 → 手写签名
4. 提交后 checked_in 自动变为 true

### 方式 3：一键全签到（仅限应急）

> **前置条件：主办方已线下核验全部人员实际到场。**
> 绝不可为了绕过系统校验而对未到场人员使用。

1. 打开 `players.html`
2. 登录（赛事码 + 裁判长密码）
3. 点击"一键全签到"
4. 确认所有选手 checked_in 变为 true

**验证点：**
- [ ] 所有 24 名选手 checked_in = true
- [ ] waivers 表有签名记录（方式 2）

---

## Phase 5: 核碰下发

**操作人：裁判长**

1. 在 master 面板确认所有房间状态
2. 点击"⚡ 扫描核碰双方盲排，并下发至裁判队列"
3. 确认提示"核碰了 2 个房间，下发 6 场比赛"（每房间 3 盘）
4. 查看任务列表确认任务已生成

> **注意：未排阵的房间不可下发。禁止强行下发空白对阵。**

**验证点：**
- [ ] 下发场数 = 预期（每房间盘数 × 房间数）
- [ ] 任务 ID 格式正确（T01-01, T01-02, T01-03, T02-01...）
- [ ] 房间状态变为 completed
- [ ] 每场任务的 t1p1/t1p2/t2p1/t2p2 来自排阵数据

---

## Phase 6: 裁判执裁

**操作人：裁判**

1. 打开 `referee.html`
2. 输入赛事码 + 裁判身份
3. 提取任务（应看到已下发的比赛）
4. 选择一场任务 → 点击"开始 setup"
5. **关键验证**：选手身份校验通过（不弹窗阻断）
6. 进入挑边步骤 → 选择方位和发球权
7. 进入计分步骤 → 模拟打几分 → 提交
8. 签名确认

**验证点：**
- [ ] 选手校验通过（不被阻断）
- [ ] 挑边流程正常
- [ ] 计分和提交正常
- [ ] 赛果归档成功
