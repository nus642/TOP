🌟 系统总览与五大入口

本系统是一套专为 Pickleball 打造的全栈数字引擎。摒弃传统的纸笔记录，实现从 选手签到免责 -> 领队盲排 -> 自动配对下发 -> 平板裁判记分 -> 法务归档 的全闭环。

1. 总控大厅 (master.html)
裁判长专属。创建赛事、导入网球记表格、分发授权链接、监控全局。
2. 执裁终端 (referee.html)
临场裁判专属。提取对阵、挑边、记分（支持每球得分/发球得分）、伤停、签名。
3. 检录中心 (checkin.html)
运动员专属。输入姓名与身份证、签署免责声明。支持现场加报建档。
4. 领队排阵 (team_lineup.html)
团体赛领队专属。盲排布阵，未签到队员将标红警告。
5. 裁判大数据库 (umpire.html)
裁判长/裁判长专属。长期留存裁判档案、自动统计执裁场次、颁发荣誉证书。

👑 裁判长 (赛会主控) 标准操作流程

Step 1：创赛与授权分发

  • 在 master.html 登录页，点击“创建全新赛事”，设置密码。
  • 登入大厅后，在顶部点击右侧的 分发裁判。系统会生成一条免密链接，请将其发送至“裁判工作群”，裁判点击即可直接登入打分板。

📌 场景 A：团体赛调度法 (Team Mode)

  1. 配置模板： 在控制台左侧配置各盘类型（如混双、男双）。
  2. 导入名单： 点击 导入大名单，上传网球记下载的参赛人员表。
  3. 导入赛程： 点击 解析团体日程，上传网球记的赛程表。此时雷达室会生成“对抗房间”。
  4. 通知领队： 让双方领队进入排阵端交卷。系统将监控交卷状态。
  5. 核碰下发： 当某房间两队均显示 [阵容已定] 时，点击底部的 ⚡ 扫描核碰双方盲排，系统会自动拆解为 3~5 场子比赛，并丢入“待办提取池”。

📌 场景 B：个人/双打赛调度法 (Ind Mode)

  1. 导入名单： 上传签到表建立身份库。
  2. 导入赛程： 上传网格表或日程表，系统将一次性把几十场比赛解析入“待办提取池”。

Step 3：法务与归档

在右下角的“完赛归档”区：

  • 可随时点击 阅签 查看已打完的赛果和防伪签名。
  • 比赛结束后，点击 一键打包下载全案资料 (ZIP)，系统会将成绩单、选手免责图、裁判确认单全部打包导出，做到法务滴水不漏。

👨‍⚖️ 裁判员 (平板终端) 执裁指南

1. 认领任务与检录

从裁判长处的链接进入后，在下拉框选择您要执裁的场次，点击 提取，载入参数。
点击黄色的 ▶ 校验全员检录并进场。系统将自动联网核对场上4人是否已签署免责协议，未签者系统将阻断开赛。

2. 挑边与站位设定

点击 裁判抛币 决定发球权。
⚠️ 核心步骤： 请务必正确选择哪队在您的左手边，并录入双打时 站在右侧(偶数区) 的球员姓名。系统将自动接管后续的所有换位计算。

3. 沉浸式记分板

比赛开始后，只需点击左/右下方的巨大 +1 按钮。
系统会自动处理发球得分制（Sideout）的 1发/2发 逻辑。如果是双打，还会动态高亮当前应该发球的选手。
点错比分？点击下方 ↩️ 撤回上一回合 即可。

4. 签名完赛

达到目标分后，点击弹出的 🏁 局点达成。
请务必让 胜方代表 在白板内手写签名，随后点击上传战果，即可清空画板准备下一场。

🏆 领队 (排阵端) 操作指南

  1. 访问 team_lineup.html。输入赛事码、房间号和本方队伍名称。
  2. 界面将渲染出裁判长设定的比赛盘数（如三盘两胜）。
  3. 在下拉框中挑选出场队员。注意：若队员名字呈红色，说明他尚未去检录中心签署免责协议！ 请督促其立刻手机扫码签到。
  4. 所有队员标绿后，点击 锁定并提交防伪阵容。一旦提交，系统上链锁死，不可再更改。

🙋‍♂️ 运动员 (签到端) 必看指南

  • 比赛当日，请第一时间扫码打开 checkin.html。
  • 在搜索框输入您的真实姓名，系统会自动从大名单中匹配。
  • 输入身份证后 4 位，并在纯白色的画板区域 手写正楷签名。
  • 警告： 此签名具有法律效力！若您未签到，将无法被领队排入阵容，裁判终端也将拒绝为您开赛！

❓ 常见疑难排解 (FAQ)

Q1: 导入团体赛程时，队伍名称对不上怎么办？

系统具有【智能模糊对齐】功能。如果网球记日程表里的队名（如“A组 万科队”）和大名单（如“万科队”）不完全一样，系统会弹窗询问您是否为同一支队伍。点击“是”，系统会在内存中自动建立翻译映射，完美解决！

Q2: 比赛进行到一半刷新了页面，比分会丢吗？

绝对不会。 裁判平板具有【防灾恢复机制】。即使手机没电关机，换台手机重新登录，系统也会提示“检测到未完结数据”，点击恢复，上一秒的比分、暂停数、发球人位置将100%还原。

Q3: 临时有野队报名，或者裁判需要换人怎么办？

系统支持全动态热更新。
裁判长可在总控大厅点击“手动新增”，系统会自动分配诸如 P102 的三位编号。
裁判员可以在 umpire.html 自行填写名字和身份证尾号完成“自助建档报到”。

Q4: 点击“分发授权链接”为何没反应？

部分浏览器会拦截静默复制。系统已升级物理降级机制。点击分发后，会弹出一个输入框，请长按文字 -> 全选 -> 复制，然后粘贴发给对应人员即可。
